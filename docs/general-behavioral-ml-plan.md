# Historical general behavioral modeling roadmap

Superseded on 2026-10-25 by the [active portfolio showcase plan](../plan.md).

The general-purpose classifier proposal is retired. Portable and pooled synthetic-data experiments did not establish reliable transfer to arbitrary uploads. No further dataset search, source pooling or portable-model promotion is planned for the showcase.

Keep the implemented behavioral observations and graph investigation modes. Use frozen V13 for the main interactive demo and explicitly experimental compatible uploads; present IEEE as separate offline benchmark evidence.
