# Improve recall while preserving precision and accuracy

The user requested substantial recall gains without sacrificing precision or accuracy. V8's full latest-period policy found 45/110 frauds with zero false alerts. Its pilot pooled precision was 97.64%, recall 48.44%. These populations are already consumed: every result in this follow-up is exploratory. No fresh confirmation or bank-effectiveness claim is allowed.

Freeze nine comparisons before running them: global recall maximization at 100% and 98% empirical calibration precision; per-channel 100% policies; a fixed three-EBM score ensemble; causal, nonrecursive same-account alert propagation; an online specialist; full-feature CatBoost; CatBoost with the online specialist; and a positive-weighted EBM with that specialist. The 98% method is a tradeoff diagnostic and earns acceptance only if actual evaluation precision is preserved. A calibration precision target is never a guarantee of future precision.

Use exactly the v8 rolling folds, seeds, sampled fitting identities and natural evaluation populations. Keep all fitting frauds and inverse-inclusion weights. Reuse existing models and predictions after hash and identity checks. New conventional comparison: 500-tree depth-six CatBoost with all v8 context/geography/feedback features. New class-emphasis comparison: the stabilized full-feature EBM with fraud weight four. Neither changes the feature definitions or reporting-delay assumptions.

The online specialist uses online transactions only, from the valid 2016H1 fit population. Both legitimate and fraudulent historical purchases are retained. Use the stable full-feature EBM. Calibrate on online 2016Q3 plus current calibration-quarter rows, deduplicated. Thus current legitimate online examples constrain transfer even when the current quarter has no fraud. Never train the specialist on recent rows and calibrate it backwards on 2016. This historical calibration is an explicit coverage workaround, not evidence of contemporary probability calibration.

All new cutoffs maximize recall subject to the declared empirical precision, using complete score-tie groups, at least ten calibration frauds and five alerts. An unsupported global policy abstains; unsupported channel cutoffs inherit that model's global cutoff. No raw scores from different model families are averaged. Burst propagation uses only prior predicted seed alerts on the same instrument account, never true fraud labels, future alerts or same-time alerts. Propagated alerts cannot seed a chain.
