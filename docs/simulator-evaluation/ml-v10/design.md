# Corroborate additional alerts with a second model family

This bounded follow-up was motivated by the completed v9 pilot. Burst follow-up found 30 additional frauds but added one false alert; full-feature CatBoost preserved precision and accuracy but gained only 12 detections. None passed all requirements. Preserve those failures. The new hypothesis is that complementary evidence can reject uncertain extra alerts while retaining more of the recall gain.

Freeze exactly three candidates before scoring them. **Guarded burst:** retain every incumbent alert; propose strictly prior, nonrecursive same-account follow-ups using the existing 1/24/168-hour and raw-score-margin 2/4 grid, then require a calibrated CatBoost corroboration cutoff. **Agreement:** retain the incumbent; rescue CatBoost high-precision alerts only when the incumbent score also exceeds a calibrated incremental cutoff. **Combined:** union of the two rescues. Rescued alerts never seed further propagation.

Select rescue cutoffs only on calibration data, using whole ties and at least five additional alerts with zero additional calibration false positives. Maximize additional detections; infeasible rescues abstain. For burst ties prefer the earlier, shorter window and smaller margin by fixed iteration order. Calibration precision is not a guarantee of future precision. The threshold sample is small and selection is optimistic; quantify evaluation uncertainty and disclose prior source exposure.

Reuse the existing v8 and v9 model scores, fitting populations and seeds; no further model training. All three periods, eligibility and evaluation denominators remain identical. Hash selected policies and prediction vectors before joining outcomes. Fit the full-data policy using the v9 full-data CatBoost and unchanged v8 full incumbent, using preceding calibration labels only. Select one candidate from the pilot before computing full-data follow-through; all full-data candidate diagnostics remain disclosed, and cannot substitute a new winner.

Retain the v9 ten-percentage-point recall target, no per-period observed precision/accuracy/recall regression, adjusted positive recall-gain lower bound and precision noninferiority lower bound above minus two points. Use 4,000 paired-user draws with confidence 1-.05/12 as a conservative allocation across the nine original and three follow-up comparisons. This does not remove adaptivity or repeated-source selection bias. Full-data follow-through uses 95% paired-user intervals and merchant sensitivity, remains descriptive, and preserves the v9 full-data gate. No automatic runtime activation follows.

Do not modify v9's frozen protocol, code or artifacts to make this follow-up appear prespecified in the original comparison. Keep plans/reminders, old models and application behavior unchanged. Apply the same strict typing, formatting, no-handwritten-code-comments and meaningful negative-control testing rules. Verify exact score reuse, complete tie handling, calibration-only selection, strictly prior/account-isolated propagation and preservation of incumbent alerts.
